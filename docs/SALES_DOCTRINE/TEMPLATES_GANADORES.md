# Templates ganadores — biblioteca de copy probado

Plantillas validadas o construidas aplicando los 10 principios + frameworks. Cada una anota: framework usado, principios activados, segmento objetivo, métrica esperada.

> Esta biblioteca arranca con templates **construidos** según doctrina. A medida que las campañas reales corran, los templates con >25% response rate se promueven aquí. Los que caen <5% se mueven a `ANTI_PATTERNS.md` con el porqué.

## T-001 — Top of mind frío puro (B2B sin urgencia)

**Framework:** StoryBrand + Cialdini (Reciprocidad + Autoridad)
**Principios activados:** P1 (pattern interrupt), P2 (especificidad), P4 (cliente héroe), P5 (CTA débil), P7 (curiosidad)
**Segmento:** Cliente que NO ha comprado dipolos en 12+ meses
**Estado térmico al recibir:** 🥶 Frío total
**Meta:** Top-of-mind, no venta inmediata

### Mensaje 1 (TEXT)
```
{primerNombre}, no le escribo para venderle nada hoy.
Le escribo para que tenga este número guardado.
```

### Mensaje 2 (IMAGE — ficha técnica P-224F + caption)
```
Hace 22 años fabricamos antenas en Curití, Santander.
Si en algún proyecto le toca cotizar dipolos VHF, queremos que sepa que existimos como opción nacional.
```

### Mensaje 3 (TEXT)
```
La línea Premium aguanta 175 km/h y 5 años de garantía escrita.
La Estándar es más asequible para proyectos de menor exigencia.
Si quiere, le mando la guía técnica completa — sin compromiso.
```

### Mensaje 4 (TEXT — cierre humano)
```
Cuando llegue el momento, me ubica acá.

John Mónoga
Gerente de Proyectos
MARAL — Curití, Santander
3177606126
```

**Métrica esperada:**
- Read rate: >80%
- Response rate: 12-18%
- Conversión a cotización: 3-6% (a 90 días)
- Conversión a pedido: 1-3% (a 365 días — el ciclo B2B largo)

**Nota:** Este template NO está diseñado para vender hoy. Está diseñado para entrar al top-of-mind. Las ventas reales se cosechan en los próximos 12 meses cuando llegue el proyecto del cliente.

## T-004 — Cliente caliente que pide cotización (cierre)

**Framework:** Hormozi (subir likelihood + bajar effort)
**Principios activados:** P2, P3, P5 (CTA fuerte), P10 (respuesta rápida)
**Segmento:** Cliente que pidió cotización
**Estado térmico:** 🔥 Caliente
**Meta:** Cerrar pedido en <72h

### Mensaje 1 — confirmación inmediata (<30min de pedido)
```
{primerNombre}, recibí su solicitud para {producto} para {ciudad}.
Le confirmo: tenemos stock para entrega en 5 días hábiles.
```

### Mensaje 2 — cotización formal (PDF)
```
Le mando la cotización formal con descuento de categoría {segmento} aplicado ({descuentoCategoria}).
Vigencia: 8 días.
```

### Mensaje 3 — refuerzo de likelihood (a las 24h si no responde)
```
{primerNombre}, ¿le revisó tu equipo la cotización?
Si hay alguna duda técnica, le explico — soy ingeniero, no vendedor.
```

### Mensaje 4 — cierre proactivo (a las 48h si confirmó interés pero no pedido)
```
Para que coordinemos producción, ¿le confirmamos el pedido para arrancar mañana?
Despacho saldría desde Curití el viernes con TCC.
```

**Métrica esperada:**
- Conversión a pedido: 50-65%
- Tiempo promedio cotización → pedido: <72h

**Principios activados:** P3 (honestidad), P4 (cliente héroe), P10 (respuesta rápida)
**Segmento:** Cliente con queja activa

John

## Cómo Marco usa la biblioteca

Cuando John pide "Marco, generá una campaña para reactivar clientes inactivos hace 6 meses con compras VHF":

1. Marco detecta segmento → "cliente inactivo + interesTags VHF"
2. Marco busca template más cercano → T-002 (reactivación)
3. Marco copia estructura, personaliza variables, valida principios
4. Devuelve copy listo + link a T-002 para que John apruebe o modifique
5. Si John modifica, Marco aprende qué prefiere y ajusta para próxima vez (Sprint 4-5)

Esto convierte cada campaña en un activo reusable, no un mensaje desechable.

## Acciones requeridas post-sesión

> Estas acciones deben ejecutarlas manualmente. El código está listo pero requieren comandos en terminal.

### 1. Instalar pdfkit
```bash
cd backend && npm install
```

### 2. Aplicar cambios de schema a la base de datos
```bash
cd backend && npm run db:push
```
> ⚠️ Si hay datos en producción, crear una migración formal en lugar de `db:push`:
> ```bash
> npx prisma migrate dev --name "fix-enums-ondelete-indices"
> ```

### 3. Variables de entorno — añadir al `.env` del backend
```env
COMPANY_NAME=Maral Tecnología y Comunicaciones S.A.S.
COMPANY_NIT=900.XXX.XXX-X
COMPANY_ADDRESS=Dirección de la empresa
COMPANY_PHONE=+57 XXX XXX XXXX
COMPANY_EMAIL=contacto@maral.com.co
COMPANY_WEBSITE=www.maral.com.co
```
